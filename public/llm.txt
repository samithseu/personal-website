## Technical Architecture

- Framework: Nuxt 4 (Vue 3, Nitro engine)
- Styling: Tailwind CSS v4 via `@tailwindcss/vite`
- Content Backend: `@nuxt/content` v3 with JSON data storage
- Performance Optimizations: Aggressive component lazy loading (`Lazy*`, `hydrate-never`, `hydrate-on-media-query`), zero-runtime build-time OG image generation via Takumi, keep-alive page caching, and native View Transitions API.
- Hosting: Vercel Edge Network
- Source Repository: https://github.com/samithseu/personal-website
